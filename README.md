# Party Game Picker

A no-install party game picker for the Friday 3:30 PM social. Browse games by player count and genre, choose which ones go in the draw, then shuffle a balanced shortlist onto a results screen.

## Features

- Browse 43 games: all 40 titles from Jackbox Party Packs 4–11, plus skribbl.io, Gartic Phone, and CrowdParty.
- Filter by player count and genre, and expand cards for game details.
- Include or exclude games from the random draw.
- Choose how many games to reveal; the picker spreads results across genres where possible.
- See each game's source, player range, and estimated round length on the results screen.
- Game cards include thumbnails and descriptions. The page runs without an install or build step.

## Use it

Open [the live picker](https://jamilfaisal.github.io/party-game-picker/) or open `index.html` in a modern browser. Choose the player count and genres, adjust the shortlist size, check the games you want included, then select **Shuffle & reveal shortlist**.

## Rank the games

Use [RANK_THE_GAMES.md](RANK_THE_GAMES.md) to rank all 43 entries from **1 (most fun)** to **43 (least fun)**. It includes each game's pack or source and a short description.

## Project files

- `index.html` — the GitHub Pages entry point and complete picker, including bundled game images.
- `jackbox-picker.html` — a compatibility redirect for the original local filename.
- `RANK_THE_GAMES.md` — the blank ranking worksheet.
- `assets/` — thumbnails for the three standalone games.

## Catalog notes

The catalog contains five games from each Jackbox Party Pack 4–11 and three standalone additions: skribbl.io, Gartic Phone, and CrowdParty. The page footer links to each source; the three standalone thumbnails are original SVG illustrations, and the short how-to-play descriptions were written for this project.
